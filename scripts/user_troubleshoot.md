# xm-bot4 双击无反应 — 用户排查指引

> 如果双击 xm-bot4.exe 后没有任何窗口弹出，请按以下步骤排查：

## 步骤一：检查是否被杀毒软件拦截

1. 打开 **Windows 安全中心**（按 Win 键搜索"Windows 安全"）
2. 点击 **病毒和威胁防护**
3. 点击 **保护历史记录**
4. 查看是否有 xm-bot4 相关的记录被标记为"已阻止"或"已隔离"
5. 如果有，点击"允许"或"还原"

> 如果你使用 360、火绒等安全软件，也请检查其隔离区。

## 步骤二：右键以管理员身份运行

1. 右键点击 `xm-bot4.exe`
2. 选择 **以管理员身份运行**
3. 如果弹出 SmartScreen 蓝色警告窗口，点击"**更多信息**" → "**仍要运行**"
4. 观察是否正常启动

## 步骤三：添加到杀毒白名单

1. 打开 **Windows 安全中心** → **病毒和威胁防护** → **管理设置**
2. 滚动到下方找到 **排除项** → **添加或删除排除项**
3. 点击"添加排除项" → 选择"文件夹"
4. 选择 xm-bot4.exe 所在的**整个文件夹**

## 步骤四：检查路径

请确保 xm-bot4 **不要放在**以下位置：
- ❌ 中文目录（如 `C:\Users\张三\桌面\工具\`）
- ❌ Program Files 目录
- ❌ 系统保护目录

建议放在：
- ✅ `D:\xm-bot4\`
- ✅ `C:\Tools\xm-bot4\`

## 步骤五：命令行诊断

1. 按 `Win + R`，输入 `powershell`，回车
2. 输入以下命令（把路径替换为实际路径）：

```
cd "D:\xm-bot4"
.\xm-bot4.exe
```

3. 观察 PowerShell 窗口中是否有错误信息输出
4. 将窗口内容**截图**发给技术支持

## 步骤六：发送日志文件

如果程序曾经闪退（而非完全无反应），可能已有日志文件：

1. 按 `Win + R`，输入 `%APPDATA%\xm-bot4\logs`，回车
2. 如果该文件夹存在，请将里面所有文件打包发给技术支持
3. 如果文件夹不存在，说明程序从未成功启动过 Python 层面
